# Bronnen

Wat er bij de modernisering (november 2026) is opgezocht, per onderwerp, met de conclusie. Bij een nieuwe keuze: eerst hier kijken of het al is uitgezocht, en of de bron nog actueel is. Veel 2026-bronnen zijn blogs; waar mogelijk de officiële documentatie aangehouden.
